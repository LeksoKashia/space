
მოცემული დავალება საინტერესო გამოწვევა აღმოჩნდა და მომცა საშუალება, გამომეყენებინა ტექნოლოგია, რომელიც ჯერ მხოლოდ თეორიულად ვიცოდი, თუმცა პრაქტიკული გამოცდილება აქამდე არ მქონია. ანგულარის ევოლუციამ საინტერესო სახე მიიღო, მუშაობა გამარტივდა და უკეთ აღსაქმელი გახდა ყველაფერი. სიგნალი სწორედ ამის საშუალებას იძლევა.

## პროექტის გაშვება
* ცხადია npm install 
* პროექტის დასასტარტად გაუშვით ბრძანება npm start, რომელიც ერთდროულად გაუშვებს ng serve და node server.js ბრძანებებს.
* შედეგად შეგვეძლება აპლიკაციის გამოყენება.
