
## შესრულებული დავალების მოკლე აღწერა
მოცემული დავალება საინტერესო გამოწვევა აღმოჩნდა და მომცა საშუალება, გამომეყენებინა ტექნოლოგია, რომელიც ჯერ მხოლოდ თეორიულად ვიცოდი, თუმცა პრაქტიკული გამოცდილება აქამდე არ მქონია. ენგულარის ევოლუციამ საინტერესო სახე მიიღო, მუშაობა გამარტივდა და უკეთ აღსაქმელი გახდა. სიგნალი სწორედ ამის საშუალებას იძლევა. ბექ ენდად JSON server გამოვიყენე, წამოღებულ მონაცემებს ngrx SignalStore ამუშავებს.

## პროექტის გაშვება
-პროექტის დასასტარტად გაუშვით ბრძანება npm start, რომელიც ერთდროულად გაუშვებს ng serve და node server.js ბრძანებებს.
-შედეგად შეგვეძლება აპლიკაციის გამოყენება.
